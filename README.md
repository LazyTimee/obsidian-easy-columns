# Easy Columns

Плагин Obsidian для управления колонками через мышь. Сборка 0.6.4: обычный Markdown без служебных префиксов цитаты, CSS Grid и основной редактор заметки. Сторонних библиотек нет.

## Формат колонок

- Новые группы создаются в формате `easy-columns`. Нажатие на текст колонки открывает исходный текст группы с курсором в конце выбранной колонки; строки не начинаются с `> >`.
- У пустой колонки в Live Preview отображается бледная подсказка «Пустая колонка», переносящаяся при сужении как обычный текст. Она не записывается в Markdown и не отображается в чтении. Разделители появляются при наведении, в том числе у пустых колонок.
- Поддерживается только fenced-формат `easy-columns`. Разбор и создание прежних callout-групп, миграция по кнопке, команды преобразования и специальные стили старого формата полностью удалены.
- В исходнике можно писать заголовки, списки, цитаты, код и другой Markdown. Разделители `---column---`, строку `widths:` и внешнюю ограду следует сохранять.
- При редактировании виден текст всей группы; флажки задач меняются в исходнике. В отображаемом блоке флажки отключены.

## Использование

- Настройки Obsidian → Easy Columns → **Язык интерфейса**: скруглённый переключатель **Русский / English**. По умолчанию — русский; выбор сохраняется и применяется сразу ко всему интерфейсу плагина.
- Настройки Obsidian → Easy Columns → **Подсказки**: включение всплывающих подсказок разделителей и кнопок. По умолчанию включено; выбор сохраняется и применяется сразу.

- В Live Preview нажмите правой кнопкой внутри обычного абзаца → **Добавить колонку**.
- Без выделения обычный текст переносится только из строки Markdown с курсором. Соседние строки остаются снаружи, даже без пустой строки между ними; отступы и пробелы сохраняются.
- То же действие доступно в палитре команд: **Easy Columns: Добавить колонку** (на английском — **Easy Columns: Add column**).
- Без выделения также поддерживаются один пункт списка с подпунктами, задача, отдельный заголовок, цитата/callout, код, таблица целиком и вложение. На пустой строке создаются две пустые колонки.
- При выделении переносится строго выделенный текст, включая смешанные блоки и их части.
- Правый клик по линии → **+** добавляет колонку в этой позиции; **×** раскрывает выбор стороны удаления.
- Непустая колонка удаляется после повторного нажатия на красную галочку. Любой другой клик отменяет подтверждение; клик вне меню закрывает его.
- Внутренние линии перетаскиваются. Двойной щелчок меняет соседей местами вместе с их шириной и содержимым.
- Правый клик по тексту внутри группы → **Выровнять ширину колонок**.
- После удаления сохраняются пропорции оставшихся колонок; единственная оставшаяся колонка становится обычным текстом.
- В режиме чтения линии скрыты, задачи внутри колонок нельзя переключать. Ссылки и выделение текста доступны.
- При ширине группы 600 CSS px и меньше колонки идут друг под другом, линии скрыты. При расширении возвращаются прежние пропорции; Markdown не изменяется. Это действует и на телефоне, и в узкой панели компьютера.
- Все изменения структуры и ширины проходят через штатную историю отмены редактора. Escape отменяет незавершённое перетаскивание.

Рабочий режим — Live Preview; Source Mode показывает исходный Markdown. Оставшаяся старая разметка отображается штатным Obsidian и не управляется плагином.

Группы сохраняются без идентификаторов. Копии различаются по позиции в документе.

## Сборка

Нужен Node.js. Установка npm-пакетов не требуется.

```text
npm run build
node --check dist/easy-columns/main.js
```

Установочные файлы: `dist/easy-columns/main.js`, `manifest.json`, `styles.css`. CSS также включён в `main.js`.
