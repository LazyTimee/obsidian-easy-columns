# Easy Columns

[English](README.md) | Русский

Создавайте колонки прямо в заметках Obsidian и управляйте ими мышью. Размещайте текст и изображения рядом, сохраняя содержимое в Markdown.

Интерфейс доступен на русском и английском языках. По умолчанию выбран русский.

## Возможности

- Создание колонок из текущей строки текста, поддерживаемого Markdown-блока или точного выделения.
- Добавление, изменение ширины, перестановка и удаление колонок мышью.
- Выравнивание ширины и штатная отмена изменений редактора.
- Несколько независимых групп колонок в одной заметке.
- Отображение в Live Preview и режиме чтения.
- Вертикальное расположение при ширине группы 600 CSS px и меньше.

## Установка

После публикации плагина в официальном каталоге Obsidian:

1. Откройте **Настройки → Сторонние плагины** и разрешите их использование.
2. Откройте каталог плагинов и найдите **Easy Columns**.
3. Нажмите **Установить**.
4. Включите плагин в списке сторонних плагинов.

Обновления устанавливаются через раздел **Сторонние плагины** в настройках Obsidian.

## Быстрый старт

1. Откройте заметку в Live Preview.
2. Поставьте курсор на строку текста или выделите текст для переноса в колонки.
3. В контекстном меню выберите **Добавить колонку** или вызовите **Easy Columns: Добавить колонку** из палитры команд.

Содержимое перенесётся в левую колонку, справа появится пустая. Без выделения обычный текст переносится только из текущей строки Markdown. У списка переносится текущий пункт с подпунктами; для заголовков, цитат, кода и таблиц учитываются границы соответствующего блока. Выделенный текст переносится строго в пределах выделения.

### Работа с колонками

- Наведите мышь на внешний край группы и нажмите **+**, чтобы добавить колонку с этой стороны.
- Перетаскивайте внутренний разделитель, чтобы менять ширину двух соседних колонок. Escape отменяет перетаскивание.
- Двойной клик по внутреннему разделителю меняет соседние колонки местами вместе с содержимым и шириной.
- Правый клик по внутреннему разделителю позволяет вставить колонку между соседями или выбрать сторону удаления. Для непустой колонки требуется повторное нажатие на красную кнопку подтверждения.
- Правый клик по тексту внутри группы позволяет выровнять ширину колонок.
- Нажатие на отображаемую колонку открывает исходный Markdown группы с курсором в конце содержимого этой колонки.

После добавления ширина всех колонок группы становится одинаковой. При удалении пропорции оставшихся колонок сохраняются; единственная оставшаяся колонка превращается в обычный текст заметки.

При редактировании исходного Markdown выберите **Добавить колонку** в контекстном меню: строка разделится в позиции курсора, а последующий текст перейдёт в новую колонку. Ширины всех колонок сразу станут равными. Каждая колонка хранит свою ширину в разделителе `---column[1050]---`. Прежние группы с `widths:` преобразуются при первом редактировании с сохранением заданных ширин. Если ширина отсутствует или некорректна, блок показывается исходным Markdown без раскладки. После выхода из блока или редактора, перехода в чтение либо другую заметку проверяются разделители; после ручного изменения числа колонок нормализуются заданные веса. Временно одна колонка сохраняет оболочку до завершения правки.

В режиме чтения элементы управления скрыты, редактирование колонок заблокировано. Выделение, копирование текста и ссылки доступны. Флажки задач изменяются через исходный Markdown.

## Настройки

Откройте **Настройки → Easy Columns**:

- **Язык интерфейса**: выберите **Русский** или **English**. Выбор применяется сразу и сохраняется.
- **Подсказки**: включите или отключите подсказки разделителей и кнопок. По умолчанию включены.

## Хранение данных

Содержимое и ширина колонок сохраняются в fenced-блоках `easy-columns` внутри заметок. Между разделителями колонок находится обычный Markdown. В режиме исходного текста и при отключённом плагине содержимое доступно без раскладки колонок.

Для редактирования используется основной редактор заметки Obsidian. Плагин не создаёт отдельных редакторов внутри колонок и не преобразует старые форматы колонок на основе callout.

## Сборка из исходников

Нужен Node.js. Установка npm-зависимостей не требуется.

```sh
npm run build
```

Альтернативная команда — `node scripts/build.cjs`. Три установочных файла появятся в `dist/easy-columns/`.

Для релизов, содержащих `.github/workflows/release.yml`, публикация GitHub Release запускает сборку его тега, создание аттестаций происхождения и загрузку трёх установочных файлов. Тег должен точно совпадать с версией в `manifest.json`.
